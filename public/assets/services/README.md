Fort Jackson Eye Care photos whenever they become available.

Stock photos are used under the [Pexels License](https://www.pexels.com/license/): free for commercial use, no
attribution required. Full-size originals are in `asset-originals/stock/`; the web versions are generated by
`npm run images -- stock`. Alt text describes what each photo shows and does not claim it was taken at the practice.

To add a photo to another service, add an entry in `src/config/images.ts` and set `image` on that service in `src/data/services.ts`.
After adding a file, set that image's `ready: true` in `src/config/images.ts`.
